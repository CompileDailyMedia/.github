# .github

Repository khusus organisasi **CompileDailyMedia**. Isinya dipakai GitHub secara otomatis:

| File | Fungsi |
| --- | --- |
| `profile/README.md` | Tampil di halaman depan [github.com/CompileDailyMedia](https://github.com/CompileDailyMedia) |
| `CONTRIBUTING.md` | Panduan kontribusi default untuk semua repo organisasi |
| `CODE_OF_CONDUCT.md` | Kode etik default |
| `SECURITY.md` | Cara melaporkan celah keamanan |
| `SUPPORT.md` | Ke mana harus bertanya atau minta bantuan |
| `ISSUE_TEMPLATE/` | Template issue default |
| `PULL_REQUEST_TEMPLATE.md` | Template pull request default |
| `LICENSE` | Lisensi kode sumber — MIT License |
| `CONTENT-LICENSE.md` | Artikel, materi belajar, logo, dan desain — hak cipta dilindungi |

File di sini berlaku untuk setiap repo di organisasi yang **tidak** punya file sejenis sendiri,
**kecuali `LICENSE`**: GitHub tidak mewariskan lisensi ke repo lain.

## Memakai Lisensi di Repo Lain

Salin `LICENSE` ke root repository baru. Kalau repo itu juga berisi konten editorial (artikel,
materi belajar, aset logo), sertakan juga `CONTENT-LICENSE.md` supaya jelas bahwa lisensi MIT
tidak mencakup konten tersebut.

Pertanyaan soal lisensi: [admin@compiledaily.net](mailto:admin@compiledaily.net).
